About this model

Full 1123 × 843 model grid, 559,985 active cells. Native terrain and water geometry; water elevations are DEM + depth. No vertical exaggeration. Narrow wet strips can be omitted where a mesh triangle contains a dry vertex.

The charts show preceding-minute means. Displayed fields are saved every five minutes, with no temporal interpolation. Browser graphics use Float32; original FP64 hydraulic results are retained.

NZTM2000 / EPSG:2193 · NZVD2016. This is a design-rainfall demonstration, not a reconstruction of an observed flood.
